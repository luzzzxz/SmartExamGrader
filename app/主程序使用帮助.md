# 答题批改系统主程序使用帮助

> 局域网网页上传与后台批改请参阅同目录下的 `局域网阅卷服务_最小版说明.md`。

> 适用程序：`enhanced_answer_card_gui_stats.py`  
> 文档版本：2026-09-02  
> 推荐入口：主程序顶部菜单“帮助 -> 主程序使用帮助”

这份说明按实际操作顺序编写。时间久了忘记怎么用时，先看“最快批改流程”和“模板怎么选”，再按所用模板查看对应章节。

## 1. 最快批改流程

### 1.1 试卷直接批改模板：推荐的一键流程

适用于在试卷选项前印有小方框、主观题直接写在横线上的双面试卷。

学生扫描文件夹建议包含：

```text
0.1.jpg / 0.01.jpg         空白正面模板
0.2.jpg / 0.02.jpg         空白背面模板
0.3.jpg                    第1名学生正面
0.4.jpg                    第1名学生背面
0.5.jpg                    第2名学生正面
0.6.jpg                    第2名学生背面
某某模板.docx              文件名含“模板”，内有参考答案和计算题信息
某某知识点.csv             本套试卷题号与知识点信息
```

操作：

1. 在顶部“当前模板”选择“试卷直接批改模板-v1”。
2. 点“选文件夹”，选择上面的目录。
3. 点“自动设置并批改上传”。
4. 程序依次完成：读取 `0.1/0.2` 或 `0.01/0.02`、识别正反面结构、读取 Word 答案、读取知识点 CSV、设置计算题、保存答案方案、批改学生卷、OCR、上传需要人工处理的题。
5. 任一环节不满足要求，程序会提示并停止，不会继续硬套。
6. 在网页 `https://your-manual-grading-server.example.com` 完成人工题，回到本机点“取网页分”。
7. 打开“整卡标注预览”检查，最后导出 PDF、CSV 或题库数据。

注意：`0.1/0.2` 和 `0.01/0.02` 都可以作为空白模板编号。自动批改会识别实际使用的这一对并跳过，不会把它们当成学生卷。

### 1.2 通用手动流程

1. 选择正确模板。
2. 点“选文件夹”。
3. 选择或创建班级，确认名册。
4. 点“设置标准答案”，加载旧方案或建立新方案。
5. 如试卷结构变化，先设置结构，再填写答案。
6. 创建“测试/调查”，让进度有正式绑定对象。
7. 点“开始批改”。
8. 点“OCR并上传”或进入“主观批改”。
9. 完成人工分数后查看统计和整卡标注。
10. 导出结果。

## 2. 模板怎么选

### 2.1 试卷直接批改模板-v1

用于：

- 学生直接在整张试卷上答题。
- 选择题在 `□A、□B、□C、□D` 前填涂或划记。
- 主观题答案写在横线上。
- 正反面都可以有选择题和主观题。
- 作图题下方有用于定位的横线，或模板中用蓝框标出作图范围。
- 背面底部可以设置计算题人工打分区域。

这套模板每份新试卷通常都要保存自己的正反面结构，答案方案会把结构和答案一起保存。

### 2.2 客观主观混合模板-v1

用于早期混合答题卡：学号区、固定选择题填涂区、固定填空区、实验题、作图题和可选计算题背面。

### 2.3 客观主观混合模板-v2（边缘定位块）

用于新版混合答题卡。它与 v1 的模板图片、定位块和坐标分开，不能互相套用答案结构。

### 2.4 错题采集模板-tc

用于只采集学生错题、生成错题本和 AI 分析数据。它更重视每题是否出错，不一定包含完整主观题分数。

## 3. 班级与学号

入口：“设置 -> 班级管理”。

可以：

- 创建班级。
- 删除班级。
- 添加或修改学生编号和姓名。
- 删除学生。

学号必须按文本保存，`0000`、`0404` 等前导零不能省略。当前名册已包含最新录入的 `24-1班` 和 `24-6班`。如果需要从一批答题卡重新提取姓名和学号，可使用项目内 `extract_roster_from_cards.py` 生成待确认表；确认后再导入班级，避免 OCR 结果直接覆盖正式名册。

学号以文本保存，前导零必须保留，例如 `0001` 不能写成数字 `1`。

选择学生图片文件夹后，程序会尝试根据上一级目录名称匹配班级，例如：

```text
D:\gj\23-1\电功率
```

会优先匹配“23-1班”，测试建议名称为“23-1\电功率”。自动匹配后仍应看一眼主界面的班级框。

学号识别不使用 OCR，而是根据模板坐标比较每个数字位置的墨迹。常用设置在“设置 -> 设置阈值”：

- 学号区阈值默认 `90`。
- 学号区采样半径默认 `14`。
- 浅涂漏识别时先适当降低学号阈值。
- 扫描偏移导致没有取到填涂中心时，再调整采样半径。

## 4. 文件夹、测试、答案方案分别是什么

这三个概念非常重要：

| 名称 | 作用 |
| --- | --- |
| 文件夹 | 存放学生扫描图片及导出文件 |
| 测试/调查 | 数据库中的一次正式批改记录，用来绑定进度 |
| 答案方案 | 标准答案、OCR设置、试卷结构、计算题和知识点配置 |

选择文件夹后，程序会优先加载这个文件夹已绑定的测试；如果没有，就按“上级文件夹名\\当前文件夹名”自动创建测试。答案和试卷结构会保留，方便同一份试卷连续批改多个班，并复制为新测试自己的快照；学生结果不会从上一个班带过来。

正式批改前会核对测试名称与答案方案名称。例如测试“24-1\\1-3章”和方案“1-3章”会直接通过；名称不对应时会先提醒确认，防止误用上一份试卷的答案。

批改、OCR、网页人工打分和计算题打分都绑定当前测试并随时保存。打开已有测试时，会恢复文件夹、模板、该测试自己的答案快照、客观题结果和主观题进度。

如果程序提示“测试与文件夹不一致”，本次批改和保存会被自动阻止。重新打开学生卷文件夹即可让程序加载或创建正确测试，不要强行继续使用旧测试。

不要同时打开两个主程序窗口。稳定启动器会阻止重复启动，避免两个窗口互相覆盖批改进度。

### 4.1 整份测试改错后重新开始

入口：“批改 -> 清除当前测试批改记录并重来”。

使用前先打开需要重改的测试。确认后，程序会清除这个测试的客观题判分、OCR结果、人工分数、统计结果和关联的网页人工任务，然后保留扫描图片和已裁小图供重新批改。

以下内容不会被删除：

- 当前测试记录及其文件夹绑定。
- 班级和学生名单。
- 答案方案、正反面结构、OCR空位设置和知识点。
- 原始扫描图片及主观题裁图。

清除前会在项目的 `recovery_backups` 目录建立自动恢复备份。这个功能只影响当前打开的测试，不影响其他班级和其他测试。

## 5. 设置标准答案

入口：“设置 -> 设置标准答案”或顶部“设置标准答案”。当前主要使用“一体化设置答案方案”窗口。

答案方案应包含：

- 选择题答案。
- 主观题标准答案。
- 同义答案、关键词、常见错答案、错误关键词。
- 前后诱导字和 OCR 开关。
- 普通空、作图题、计算题的分值。
- 正反面试卷结构或实验题结构。
- 题号和知识点 CSV。

### 5.1 选择题输入格式

逐行格式：

```text
1.A
2.B
3.D
11.AD
12.BC
```

紧凑格式：

```text
1,D;2,D;3,C;4,A;5,B;11,BD;12,AD
```

多选题直接连续写字母，例如 `AD`，不要写成 `A,D`。

### 5.2 主观题输入格式

推荐使用题号和中文分号：

```text
13.电磁波；声源处
14.不可再生；裂变
20.(1)透明；D；相等 (2)固液共存；4
21.(1)右 (2)3；便于测量力臂
```

规则：

- 题号和 `(1)(2)` 用于定位，不作为答案内容。
- 同一小题多个空优先用中文分号 `；` 分开。
- 主观题结构必须先与实际横线数量对应。
- 解析后检查窗口中的题号、空位数和答案是否一一对应。
- 数量不一致时不要强行保存，应先修改结构或答案文本。

### 5.3 作图题

作图题在结构中仍占一个主观题位置。设置结构时把对应空标记为“作图”，答案文本中保留题号并填写：

```text
7.作图
```

作图题不会走 OCR，直接进入人工打分。常用满分 2 分，步长 1 分。

### 5.4 计算题

计算题不设置标准答案，只设置题号、小题数量和每小题满分。入口：

```text
设置 -> 设置计算题分值
```

计算题裁整块答题区域，人工按大题批改。打分入口：

```text
设置 -> 输入计算题分数
```

### 5.5 一键导入答案和知识点

在一体化窗口点“一键导入答案和知识点”，程序会在当前学生图片目录寻找：

- 文件名包含“模板”的 Word 文件。
- 当前目录的知识点 CSV。

Word 中读取“参考答案”到“计算题”之间作为答案；“计算题”后的内容用于解析计算题数量和分值。方案名称默认使用当前文件夹名称。

## 6. 设置试卷直接批改结构

入口：“设置 -> 设置正反面结构（小框+横线）”或主界面“正反面结构”。

当前推荐使用彩色模板：

- 红色小方框表示选择题框。
- 红色横线表示普通主观题空。
- 蓝色框表示作图题范围。
- 四个定位块仍按原来的黑色定位块识别。

操作：

1. 程序读取当前目录的 `0.1.jpg` 正面和 `0.2.jpg` 背面。
2. 自动识别正面，再在同一预览窗口下方显示背面。
3. 编号由正面接到背面。
4. 点击误抓的小框或横线可取消，再次点击可恢复。
5. 删除或恢复后，图中编号和右侧信息同步重排。
6. 同一行按从左到右编号，整体按从上到下编号。
7. 保存正反面结构。
8. 保存后点“查看裁图”检查实际 OCR/人工会看到的范围。

选择题小方框总数应能按每题 4 个组成题目。跨页题允许正面只有部分选项、背面接上剩余选项，只要整题最终结构正确。

## 7. 查看结构和裁图

入口：“设置 -> 查看已保存结构/裁图”或主界面“查看裁图”。

这个功能比只看横线更可靠，因为它显示程序实际会送去识别的图片范围。检查：

- 正反面是否正确。
- 横线编号是否对应题号。
- 同一行是否左小右大。
- 普通空是否裁到学生书写内容，字有没有削顶。
- 裁图左右是否带入题干印刷字。
- 作图题是否包含完整作图区域。
- 计算题是否包含整块答题区域。

如果保存结构时正确、学生裁图却错，通常要检查扫描方向、正反面配对或是否加载了另一份答案方案。

## 8. 开始批改

点“开始批改”后，程序先完成：

- 四点定位和页面方向校正。
- 学号识别和名册匹配。
- 选择题填涂识别。
- 生成每名学生的客观题结果。
- 保存到当前测试。

试卷直接批改模板以空白模板中的小方框为基准，比较学生卷同一位置的灰度变化，不应重新在每张学生卷上寻找一套新小框。

双面扫描通常为：

```text
0.3 + 0.4 = 第1名学生正反面
0.5 + 0.6 = 第2名学生正反面
```

混合模板如果本次只扫描正面，要勾选“混合模板单面模式”，否则相邻学生正面可能被当成同一学生的背面。

## 9. 主观题 OCR

当前常规流程：

1. 第一轮使用 PaddleOCR 快速模型。
2. 命中任一标准答案，直接给满分。
3. 命中常见错答案或错误关键词，直接给 0 分。
4. 未识别、低置信度或无法判断的，使用 PP-OCRv6 再识别。
5. 第二轮命中标准答案，给分。
6. 两轮都没有识别到文字时按空白给 0 分；识别到文字但无法匹配答案规则时进入人工打分。
7. 标记“手改”、作图题、计算题直接进入人工。

默认置信度为 `0.6`。置信度只是 OCR 自己对文字识别的把握，最终是否得分仍以标准答案、关键词、错答案规则为准。

一个空允许填写多个正确答案，例如：

```text
增大；变大
```

“关键词”适合长句，只要识别结果包含指定核心词即可给分。“常见错答案”和“错误关键词”用于直接判错，减少无意义的人工复核。

诱导字用于给孤立单字增加上下文，例如在答案左右加常见搭配，再从 OCR 结果中去掉诱导内容。诱导设置会保存在 OCR 偏好记忆中，下次可以引用。

## 10. 人工打分

入口：“批改 -> 主观题批改”或主界面“主观批改”。

推荐：

- 先点“OCR自动判分全部试卷”。
- 再点“进入人工打分”。
- 人工模式按题号横向批改全班，再进入下一题。
- 图片下方显示标准答案，减少来回查答案。
- 点 `0/1/2` 或计算题对应分值后自动保存并前进。
- 键盘可直接使用数字键。
- “上一空/下一空”在人工任务之间移动，不应跳到无需人工的自动判分空。

如果发现机器或人工改错，不需要重新 OCR：在浏览状态切到该空，直接点正确分数即可覆盖并立即保存。

打完全部人工任务后会弹窗提示。关闭窗口前也会保存当前分数。

## 11. 网页人工打分

网页地址：`https://your-manual-grading-server.example.com`

网页登录：

1. 手机或其他电脑在浏览器中打开上面的固定地址。
2. 使用教师账号登录；账号默认为 `teacher`，密码由私密服务配置保存。
3. 首页会列出本机上传的人工批改任务，点任务名称进入。
4. 每题点分后自动进入下一项，全部完成会提示。

本机流程：

1. 点“OCR并上传”，只上传需要人工处理的题。
2. 登录网页后，在电脑或手机上打分。
3. 网页全部完成后会提示。
4. 回到本机点“取网页分”。
5. 本机会按任务 ID 和空位 ID 合并分数。
6. 获取成功后删除 VPS 上该任务，避免长期占空间。

如果网页上传了很多已自动判分题，先检查当前答案方案和 OCR 空位设置是否正确，不要直接重复上传。

## 12. 查看成绩和整卡标注

主界面输出区域会显示：

- 客观题得分。
- 填空题得分。
- 实验题得分。
- 作图题得分。
- 计算题得分。
- 总分和百分制分数。

入口“导出 -> 整卡标注预览”可以逐名查看整张试卷：

- 客观错题圈出正确选项。
- 主观错题保留红色批改标记，并可在横线下方显示正确答案。
- 作图题显示小题分和总分。
- 计算题在计算题区域左上方显示小题分与总分。
- 支持按学号或姓名搜索。
- 浏览时会预处理后续图片，提高翻页速度。

## 13. 导出功能

| 菜单 | 输出用途 |
| --- | --- |
| 导出透打标注PDF | 只输出红色标注，用于套打回纸质试卷 |
| 导出当前测试汇总 | Excel 汇总、成绩排序和高频错题 |
| 导出CSV | 简洁成绩或错题数据 |
| 导出详细结果 | 给 AI 做逐题分析的 JSON/文本 |
| 导出到题库系统 | 按题输出学生编号、姓名、题号、得分、满分 |
| 导出主观题裁图 | 调试或单独查看主观题图片 |
| 导出老师讲评透打PDF | 在模板对应位置打印全班正确率、答案、常见错答和高于平均分名单 |

学生透打可在导出前选择顶部显示“分数”或“等级”。等级按100分制划分为 A+、A、B+、B、C+、C、D、E，各档最低分可调整并会自动记住；老师讲评透打默认沿用同一显示方式。全部透打文字、数字和批改线条统一使用打印体。

老师讲评透打 PDF 使用当前测试的最终成绩：第1面顶部打印平均成绩和高于平均成绩学生，选择题打印正确率及错项人数，填空/实验打印答案、常见 OCR 错答和正确率，作图/计算题按平均得分统计；学生错题位置还可打印知识点编号。导出前应先完成并保存全部人工打分。

题库 CSV 按“一名学生一道题一行”输出，不按空位输出。学号保留前导零。

导出透打 PDF 前可保存不同打印机或纸张的偏移、缩放预设。正面和背面可分别设置。打印机机械偏移每批可能不同，先预览、少量试打后再批量打印。

## 14. 错题本和知识点分析

“工具 -> 错题本”支持：

- 单个学生错题本。
- 批量学生错题本。
- 合并学生历次错题。
- 班级总体错题本。
- 按错误人数阈值提取高频错题。

小题不会脱离大题单独抽取，例如 `25(2)` 出错会提取完整第 25 题。

“工具 -> 学生知识点分析”支持：

- 班级总体。
- 学生个人。
- 按时间段或测试范围筛选。
- 人工录入假期试卷错题。
- 导出选中薄弱知识点给题库系统。

知识点题号必须与答案方案中的题号一致，不能按 CSV 行号猜测。

## 15. 常见问题

### 程序打不开

先使用稳定版启动器。检查 Python 3.14、项目目录、常规依赖目录和控制台报错。缺少 `PIL` 是 Pillow 未加载；缺少 `openpyxl` 会影响 Excel 导出。

### 加载方案后仍说“答案未设置”

检查当前模板是否与方案模板一致；确认主观题结构空位数与答案数一致；如果已经打开测试，测试绑定的旧快照可能优先恢复，应加载正确测试和正确方案后保存。

### 学号或选择题突然很差

检查是否换了试卷结构却仍加载旧方案、扫描分辨率是否改变、正反面是否配对正确、模板图是否被覆盖。不要一开始就反复调阈值。

### 裁图上下颠倒或立起来

检查正面方向和文件配对。背面一般跟随正面的旋转方向，不应单独依赖残缺定位块判断。

### 修改分数后又重新裁图

正常的分数修改不需要重新裁图。应进入已有主观题浏览，直接修改分数；只有模板、结构、坐标或方向发生变化才需要重新裁。

### 打开测试没有主观题进度

确认打开的是同一个测试 ID，而不是同名新测试；检查测试是否绑定了原文件夹；关闭程序前不要强制结束任务。

### PDF 分数与界面不一致

确认只打开一个程序窗口，保存人工分数并刷新统计，再重新生成 PDF；同时确认打开的不是旧 PDF。

## 16. 使用时最重要的五条原则

1. 新试卷先确认模板和结构，再填答案。
2. 先打开学生卷文件夹；程序会自动创建或加载测试，再开始正式批改。
3. 每次加载方案后检查模板、答案数和裁图预览。
4. 修改分数不重新裁图，修改结构才重新裁图。
5. 不要同时打开两个主程序，也不要用任务管理器强制结束正在保存的程序。

## 17. 2026-09-14 保存及异常提示更新

- 打开旧测试会读取该测试保存的答案；若要使用新版公共方案，请在答案设置中明确加载后保存。
- 出现“成绩文件读取失败”“属于其他测试”或“模板不一致”时，原文件会保留。应核对当前测试并从备份恢复，不能把损坏文件直接当作空成绩重写。
- 网页分数只有保存成功才会自动前进；出现保存失败时应重试。本机取分发现学生或空位不匹配时会停止，并保留服务器任务。
- 大模型回复格式异常或分数无效时保留待人工处理；不会把这类失败自动记为成功 0 分。
