# 批改结果按需导出

2026-09-17 后续修订：成绩和视图保持联动，文件在用户主动导出时才生成。本文取代《评分修订与输出联动_20260917.md》中关于退出、保存及单空更正后自动重建文件的说明。

## 原因

此前把 `refresh_linked_outputs()` 放进了快速批改窗口关闭和单空更正流程，即使用户没有要求输出，也会检查并重建已登记文件。

更深一层，浏览函数 `refresh()` 会调用 `clear_stale_auto_scores()`。这个函数不仅查看记录，还可能撤销或补判部分自动分。用户只是翻页，也可能产生评分变化。另一个放大因素是结果版本计算包含保存时间等元数据，容易把保存过程当作内容变化。

## 当前行为

| 操作 | 成绩与视图 | PDF / HTML / Excel / 网页 |
| --- | --- | --- |
| 浏览、翻页 | 显示已有评分，不隐式补判或撤销评分 | 不生成、不覆盖、不上传 |
| 更正答案、人工改分 | 保存评分，更新总分、排名、统计和预览 | 不自动生成或上传 |
| 保存、退出快速批改 | 保存进度及数据库结果 | 不自动生成或上传 |
| 主动导出某种文件 | 从当前测试的已保存评分重新汇总 | 只生成用户选择的输出；课件导出保留原有发布流程 |

已删除批量自动重建函数，以及浏览刷新中的隐式评分函数。明确的 OCR 批改、人工评分、单空更正和逐空规则修订入口继续生效。

结果版本比较忽略保存时间、历史记录和成绩文件路径等不影响当前展示的元数据。真实分数、答案或试卷数据变化仍会刷新视图。

导出记录和文件归属信息保留用于追溯，不能触发自动输出。现有导出文件保持原样；用户需要新版时主动导出即可，不需要先登记旧文件才能使用新成绩。

## 验证

`py -3.14 -m unittest discover -s app/tests -q`：112 项通过。

本次替换了已不适用的自动重建测试，新增或调整：

- 执行真实浏览回调，反复翻页后待复核记录及其他评分不变。
- 执行真实关闭回调，分别验证未改分、有改分两种情况：保存进度成功，不调用导出或上传，不修改现有文件。
- 单空更正后，已导出 PDF/HTML/Excel 的内容和修改时间保持不变；随后主动导出，透打分值和课件统计使用最新成绩。
- 只导出 PDF 时不连带生成 HTML；实际分数变化仍更新预览，单纯保存时间变化不触发预览刷新。
- 原有跨测试隔离、逐空修订、数据库总分、排名、输出失败保护等测试继续通过。

测试仅使用临时文件、数据库和模拟网络，不调用真实 OCR 或上传学生数据。
