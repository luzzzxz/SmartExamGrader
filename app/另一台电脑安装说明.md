# 答题批改系统：另一台电脑安装说明

> 文档版本：2026-09-03  
> 适用系统：64 位 Windows 10/11

## 1. 先说明压缩包里有什么

新备份包是一个可迁移的私有完整包，包含：

- 主程序和相对路径启动器。
- Python 3.14 使用的常规运行库。
- 当前班级、学生名单、答案方案、试卷结构和批改进度。
- 知识点总表、知识点映射、网页人工打分和题库桥接配置。
- 主程序帮助及维护文档。

压缩包**不包含 Python 本体、PaddleOCR 虚拟环境和 OCR 模型**。Python 和 OCR 环境与电脑上的安装路径有关，直接打包旧电脑的虚拟环境并不可靠。

此包含学生姓名、成绩和服务器配置，只能作为个人私有备份保存，不要公开分享。

## 2. 新电脑需要安装什么

### 必须安装

1. **Python 3.14 64 位**：运行主程序。
2. 解压软件：Windows 资源管理器自带的“全部解压”即可。

### 使用主观题 OCR 时还要安装

1. **Python 3.13 64 位**：建立独立 PaddleOCR 环境。
2. PaddleOCR 依赖：由包内 `安装OCR环境.bat` 自动安装。
3. OCR 模型：首次识别时联网自动下载，或从旧电脑复制。

当前验证版本：

```text
主程序 Python：3.14.4
OCR Python：3.13.13
PaddleOCR：3.7.0
PaddlePaddle：3.2.2（CPU 版，无需 CUDA）
PaddleX：3.7.1
```

不要用 Python 3.14 创建 PaddleOCR 环境。当前已经验证可用的是 Python 3.13。

## 3. 安装 Python 3.14

1. 安装 64 位 Python 3.14，建议与当前版本一致或使用同系列的较新修订版。
2. 安装界面勾选 `Add python.exe to PATH`。
3. 保留 `pip`、`py launcher` 和 `tcl/tk and IDLE`；图形界面依赖 Tkinter，不能取消 Tcl/Tk。
4. 安装结束后打开“命令提示符”，执行：

```bat
py -3.14 --version
```

应显示 `Python 3.14.x`。

## 4. 解压并第一次启动

1. 将压缩包完整解压，不要直接在压缩包预览窗口内运行。
2. 建议解压到短而固定的可写目录，例如：

```text
D:\答题批改系统
```

3. 双击包根目录的 `启动答题批改系统.bat`。
4. 主程序常规依赖已放在 `runtime\pydeps314`，通常无需再次安装。
5. 如果启动器没有找到 Python，可在命令提示符确认 `py -3.14 --version` 正常，再重新启动。

如果包内 `runtime\pydeps314` 被误删，可在包根目录打开命令提示符后执行：

```bat
py -3.14 -m pip install -r app\requirements-main.txt
```

## 5. 安装 PaddleOCR

### 推荐：自动安装

1. 先安装 Python 3.13 64 位，并勾选 PATH、pip、py launcher 和 Tcl/Tk。
2. 确认：

```bat
py -3.13 --version
```

3. 双击压缩包根目录的 `安装OCR环境.bat`。
   如果没有 Python 3.13，新版脚本会先尝试执行 `py install 3.13` 自动安装。
4. 脚本会在以下目录创建独立环境：

```text
app\paddleocr_env
```

5. 安装完成后重新启动主程序。

### 手动安装

在包根目录打开命令提示符，依次执行：

```bat
py -3.13 -m venv app\paddleocr_env
app\paddleocr_env\Scripts\python.exe -m pip install --upgrade pip setuptools wheel
app\paddleocr_env\Scripts\python.exe -m pip install -r app\requirements-paddleocr.txt
app\paddleocr_env\Scripts\python.exe -m pip check
```

验证导入：

```bat
app\paddleocr_env\Scripts\python.exe -c "import paddle, paddleocr, paddlex; print('PaddleOCR OK')"
```

看到 `PaddleOCR OK` 才表示 OCR 环境完整。

## 6. OCR 模型如何准备

程序当前使用：

- 第一轮：`PP-OCRv5_mobile_det`、`PP-OCRv5_mobile_rec`。
- 第二轮复核：`PP-OCRv6_medium_det`、`PP-OCRv6_medium_rec`。

### 新电脑可以联网

第一次运行 OCR 时等待模型自动下载。首次会比以后慢，下载结束后会缓存在：

```text
C:\Users\新电脑用户名\.paddlex\official_models
```

### 新电脑不能联网

从旧电脑复制整个目录：

```text
C:\Users\Administrator\.paddlex\official_models
```

到新电脑当前登录用户对应的：

```text
C:\Users\新电脑用户名\.paddlex\official_models
```

当前旧电脑模型约 363 MB。必须保持 `official_models` 下各模型子目录名称不变。

## 7. 安装后的检查顺序

建议不要一开始就批改整班，先按下面顺序检查：

1. 双击启动器，主界面能够打开。
2. 打开一个已有测试，班级、答案方案和历史分数能恢复。
3. 打开答案方案，确认选择题、主观题、试卷结构和知识点都存在。
4. 用一份学生卷测试学号和选择题识别。
5. 只测试少量主观题，确认 PP-OCR 快速识别和 v6 复核都能运行。
6. 打开人工打分网页，确认 `https://your-manual-grading-server.example.com` 可访问。
7. 导出一份整卡预览或 PDF，确认中文字体和打印位置正常。

## 8. 哪些功能还依赖外部条件

- 网页人工打分需要网络，并使用当前 VPS 配置。
- 向 VPS 题库发送知识点时，题库地址填 `https://your-question-bank-server.example.com`。
- 使用本机题库时，地址填 `http://127.0.0.1:8765`，并先启动本机题库系统。
- Word 答案读取不要求安装 Microsoft Word；程序使用 `python-docx` 读取。
- PDF 浏览和打印建议安装一个正常的 PDF 阅读器，但 PDF 生成不依赖 Office。
- 中文透打会优先使用 Windows 字体目录中的微软雅黑或黑体。

## 9. 常见问题

### 双击后提示找不到 Python 3.14

重新安装 Python 3.14，并勾选 PATH 和 py launcher。然后确认：

```bat
py -3.14 --version
```

### 主界面能开，但 OCR 提示环境不存在

说明 `app\paddleocr_env\Scripts\python.exe` 不存在。安装 Python 3.13 后运行 `安装OCR环境.bat`。

如果出现 `No runtime installed that matches 3.13`，在命令提示符运行：

```bat
py install 3.13
```

安装完成后再次运行 `安装OCR环境.bat`。如果当前 `py` 不支持 `install` 命令，请从 Python 官方安装 64 位 Python 3.13，并保留 pip 和 py launcher。

### OCR 第一次长时间没有结果

通常是在下载模型。保持网络连接并等待；也可以从旧电脑复制 `.paddlex\official_models`。

### 出现 DLL load failed 或 Paddle 无法导入

1. 确认安装的是 64 位 Python 3.13。
2. 删除失败的 `app\paddleocr_env` 后重新运行 `安装OCR环境.bat`。
3. 安装或修复 Microsoft Visual C++ 2015-2022 x64 运行库后再试。

### 换电脑后网页打分或题库连接失败

先检查网络，再检查主程序中的服务器地址。配置文件随私有备份带入，但服务器状态、域名和密码不会由本地程序自动修复。

### 旧电脑和新电脑同时打开同一个共享目录

不要这样使用。数据库和进度文件可能被两台电脑同时写入。迁移完成后，同一份包同一时间只在一台电脑运行。

## 10. 数据安全与再次备份

- 每次批改结束正常关闭窗口，让程序保存当前测试进度。
- 复制或打包前先关闭主程序，避免数据库正在写入。
- 新电脑确认运行正常前，不要删除旧电脑原项目。
- `answer_card_app.db`、`answer_keys` 和三个 `session_*` 目录是重要数据。
- 新压缩包内有 `PACKAGE_MANIFEST_SHA256.txt`，用于核对每个文件是否完整。
